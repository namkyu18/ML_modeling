# 미국 주식 분석 시스템

실시간 데이터를 기반으로 한 전문적인 주식 분석과 매매 신호를 제공하는 웹 애플리케이션입니다.

## 🚀 주요 기능

### 📊 섹터 분석
- 11개 주요 섹터 ETF의 현재 상황 분석
- 50일선과 200일선 위에 있는 주식 비율 기반 매매 신호
- 섹터별 주요 구성 종목 및 투자 추천

### 🔍 개별 주식 분석
- 실시간 주식 데이터 및 기술적 지표 분석
- 이동평균선, RSI, MACD, 볼린저 밴드 등 종합 분석
- 캔들스틱 차트와 인터랙티브 시각화
- 매수/매도 신호 및 근거 제공

### ⚖️ 주식 비교 분석
- 여러 주식 동시 비교 분석
- 투자 우선순위 결정 지원
- 포트폴리오 구성 추천

## 📈 분석 지표

### 기술적 지표
- **이동평균선**: 20일, 50일, 200일 이동평균선
- **RSI**: 상대강도지수 (과매수/과매도 구간)
- **MACD**: 이동평균수렴확산지수
- **볼린저 밴드**: 변동성 기반 상하한선
- **거래량 분석**: 평균 거래량 대비 현재 거래량

### 매매 신호
- **BUY**: 강한 매수 신호
- **STRONG_BUY**: 매우 강한 매수 신호
- **HOLD**: 관망 신호
- **SELL**: 매도 신호

## 🛠️ 설치 방법

### 1. 필요한 라이브러리 설치
```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행
```bash
python app.py
```

### 3. 웹 브라우저에서 접속
```
http://localhost:5000
```

## 📋 필요 라이브러리

- **Flask**: 웹 프레임워크
- **yfinance**: Yahoo Finance API를 통한 주식 데이터 수집
- **pandas**: 데이터 처리
- **numpy**: 수치 계산
- **plotly**: 인터랙티브 차트 생성
- **ta**: 기술적 분석 지표 계산

## 🎯 사용법

### 메인 대시보드
1. 홈페이지에서 전체 시스템 개요 확인
2. 빠른 분석을 위한 주식 검색 기능
3. 섹터 현황 요약 정보

### 섹터 분석
1. 11개 섹터의 현재 상황 한눈에 파악
2. 각 섹터별 상세 정보 및 구성 종목
3. 섹터 기반 투자 추천

### 주식 분석
1. 원하는 주식 티커 입력 (예: AAPL, MSFT)
2. 분석 기간 선택 (6개월, 1년, 2년, 5년)
3. 종합적인 기술적 분석 결과 확인
4. 매매 신호 및 근거 검토

### 주식 비교
1. 비교하고 싶은 주식들 추가
2. 또는 사전 설정된 조합 선택
3. 비교 분석 결과 및 투자 우선순위 확인

## ⚠️ 주의사항

- 본 시스템은 투자 참고용 정보 제공 목적입니다
- 실제 투자 결정은 본인의 판단과 책임 하에 하시기 바랍니다
- 과거 데이터 기반 분석으로 미래 수익을 보장하지 않습니다
- 시장 상황에 따라 신호의 정확도가 달라질 수 있습니다
